## 🚀 Getting Started

**Prerequisites:** Node.js 18+

```bash
# 1. Clone
git clone https://github.com/mdwarishansari/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview

# 6. Lint
npm run lint

# 7. Generate project preview screenshots (needs network + Playwright)
npx playwright install chromium   # first time only
npm run previews
```

## 🌍 Deployment

### Vercel *(Recommended — zero config)*
1. Import the repository at [vercel.com](https://vercel.com)
2. Framework preset: **Vite**
3. Build command: `npm run build`
4. Output directory: `dist`
5. Vercel auto-deploys on every push to `main`

### Manual / Other Hosts
```bash
npm run build   # produces dist/
# Serve dist/ as a static site from any host
```

## 🎨 Customization Guide

### Updating content

| File | What it controls |
|------|-----------------|
| [`personal.ts`](./src/data/personal.ts) | Name, email, hero copy, about text, footer |
| [`projects.ts`](./src/data/projects.ts) | Project cards — title, links, order, preview slug |
| [`skills.ts`](./src/data/skills.ts) | Skills, proficiency levels, categories |
| [`certifications.ts`](./src/data/certifications.ts) | Cert cards with images and verify links |
| [`experience.ts`](./src/data/experience.ts) | Work experience timeline |
| [`socials.ts`](./src/data/socials.ts) | Social media links and handles |

### Adding a new project

1. Add an entry in [`src/data/projects.ts`](./src/data/projects.ts) with a unique `slug` and `order`
2. Add a preview image at `public/project-previews/<slug>.webp`
   — or run `npm run previews` to auto-capture it from the live URL

### Changing brand colors

Edit `src/styles.css` under `@theme inline`:

```css
--color-plum:  #8052ff;  /* Primary accent */
--color-void:  #000000;  /* Page background */
--color-bone:  #ffffff;  /* Primary text */
--color-amber: #ffb829;  /* Secondary accent */
--color-ash:   #9a9a9a;  /* Muted text */
```

## ⚡ Performance Notes

| Optimization | Detail |
|-------------|--------|
| **Lazy sections** | Certifications, Experience, Social are code-split and loaded on demand |
| **Hash navigation** | Retry loop re-checks for lazy-mounted sections up to 3 s after load |
| **Canvas background** | Spatial grid reduces particle connection work from O(n²) → O(n) |
| **Non-blocking fonts** | Inter font loaded via `rel=preload` + `onload` swap — zero render-block |
| **Passive listeners** | mousemove/resize/scroll all use `{ passive: true }` |
| **Three.js chunk** | Split into `three-vendor` chunk — only downloaded when Hero mounts |
| **Image loading** | Project previews use `loading="lazy"` with WebP format |
